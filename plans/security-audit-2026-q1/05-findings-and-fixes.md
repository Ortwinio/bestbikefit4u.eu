# Step 05 — Findings and Fixes

## Objective

Fix all P0/P1 findings from Steps 01–04. Document P2/P3 for backlog.

## P0 Fix Protocol (do immediately)

For each P0 finding:
1. Fix the code
2. Add a test or manual verification step
3. Document what was changed and why

## P1 Fix Protocol

For each P1 finding:
1. Assess blast radius of fix
2. Fix or create a tracked issue with due date

## P2/P3 Backlog

List deferred items in this format:
```
- [P2] <location>: <issue> — accepted risk / deferred to <target>
```

## Output

Document in `output-05-findings-and-fixes.md`:
- P0 fixes applied
- P1 fixes applied or tracked
- P2/P3 backlog
- Updated security posture assessment vs. original audit
- Recommended next review date (suggest: 2026-Q2, ~June 2026)
