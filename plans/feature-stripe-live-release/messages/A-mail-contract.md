# Billing delivery contract

`queueBillingEmail(ctx, { kind, userId, sendKey, entitlementId?, launchAt?, transitionOfferId?, transitionRunId? })` in `convex/emails/billingQueue.ts` persists a deduplicated job and schedules `emails/billing:sendBillingEmail` with `{ jobId }` immediately. Kinds: purchase, welcome, cancellation, renewal, expired, transition_announcement, transition_reminder. Returns true for newly queued, false for duplicate or disabled. Call inside the entitlement transaction.

Billing flags guard queue and claim. Only prelaunch transition announcements may bypass disabled billing: `transitionRunId` must identify an applied announcement run matching launch date, backed by a completed dry-run with the same admin, kind and date and reciprocal applied-run reference. This enables the explicit prelaunch admin workflow without enabling payment mails.

New additive table `billingEmailJobs`: sendKey/user/status indexes, kind, userId, entitlementId, launchAt, transitionOfferId, transitionRunId, status, attempts, createdAt, firstAttemptAt, leaseUntil, sentAt, failureCode. Atomic claims, stable provider idempotency key derived from job ID, at most six delivery attempts within 20 hours, expiring leases and scheduled retry. First actual delivery freezes its provider request in the database only, reuses identical content for ambiguous retries and clears it after confirmed send. Current preference, recipient and refund eligibility remain checked. Changed recipient fails closed.

The action reloads user service preference/locale, entitlement, immutable billing period, invoice-payment linkage and refund. Purchase/welcome await a missing payment link; full refunds cancel purchase/welcome/renewal/expiry. Immediate renewed cancellation waits for exact cancellationKey and cancellationAmountRefunded evidence matching immutable pro-rata calculation; unrelated cumulative refunds cannot release it. Rounded zero and period-end cancellation need no refund evidence. Missing evidence stays pending without consuming delivery attempts; `wakeBillingEmailEvidence(ctx, userId)` resumes on late invoice-payment/refund events. Missing configuration fails closed with bounded retries. Never log provider errors or sensitive data.

Annual-personal welcome gains an optional appointmentUrl. This owner edits pricing template/index only for that link and owns the new truthful NL/EN transition reminder template. B must not edit these template files.
