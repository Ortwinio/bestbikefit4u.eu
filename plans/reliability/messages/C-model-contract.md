# Q1 model + RangeBar contract (first handoff)

Imports: shared/reliability/saddleHeight.ts and src/components/ui/RangeBar.tsx (also UI barrel export).
All model lengths returned in mm; public input lengths in cm. Pure, no persistence or engine changes.

## Model exports

- `checkInseamPlausibility(heightCm, inseamCm)` returns `{status: "ok"|"check"|"large"|"error", expectedInseamCm, deviationRatio, direction: "shorter"|"longer"|"equal"}`. Invalid/nonfinite height or inseam, inseam>=height, outside55–105cm =>error. Thresholds inclusive5%ok, inclusive12%check.
- `calculateSaddleHeight(input)` low-level model: `{heightCm?:number, inseamCm?:number, provenance?:{kind:"derived"|"estimated"|"declared"|"measured",method?:string,repeatCount?:number,withinTolerance?:boolean,unresolvedWarning?:boolean}, bikeFactor?:number, adjustmentsMm?:{flexibility?:number,core?:number,goal?:number,climbing?:number}}`. Measured inseam defaults measured; absent inseam derived from height. Invalid inputs throw RangeError. All adjustment defaults0; factor defaults0.883. Returns `{adviceMm,halfWidthMm,lowerMm,upperMm,inseamMm,sigmaInseamMm,sigmaModelMm,scaleMinMm,scaleMaxMm}`. Sigma propagation always0.883; internal advice clamp0.86–0.91B; bounds rounded5mm, advice/halfwidth wholemm; scale advice±60mm.
- `calculatePublicSaddleHeight({heightCm?,inseamCm?,confirmed?:boolean,override?:boolean})` returns `{status:"none"|"ok"|"check"|"large"|"error", plausibility:null|<above>, result:<model result>|null, basis:"estimated"|"measured"|"height-until-remeasured", unresolvedWarning:boolean, dashed:boolean, canRefine:boolean, nextStep:{kind:"remeasure"|"add-inseam"|"save-and-repeat",halfWidthMm:number|null}}`.
- `getPublicSaddleHeightNextStep({hasInseam,unresolvedLargeWarning,result})` returns nextStep above; hypothetical next uncertainty calculated from same formula (not literal23/18).
- `SADDLE_HEIGHT_BIKE_FACTORS` = `{road:0.883,gravel:0.880,mtb:0.875,city:0.870}`; `SADDLE_HEIGHT_SCALE_HALF_WIDTH_MM=60`.

Public semantics: no inseam -> estimate; ok -> measured; check beforeconfirmation uses measured value with open-warning3%B uncertainty + dashed, afterconfirmation normal measured10mm uncertainty. Large beforeoverride uses height estimate; afteroverride uses entered inseam but warning remainsopen, uncertainty3%B + dashed; nextstep alwaysremeasure and canRefinefalse. Invalid =>noresult. CanRefine onlyok or confirmedcheck. Changing eitherinput must reset confirmed/override in UI.

Important board discrepancy: its yellow-warning script uses10mm even whilewarningopen, but README/rekenmodel explicitly say openwarning overrides to3%B. Model follows written rule; UI/QuickFix must use shared result. No hardcoded± labels. Presentation rounding follows the explicit worked example and board: round advice and half width to whole mm FIRST, then round their sum/difference to5mm. Raw sigmaModelMm is retained for uncertainty/next-step calculations. This is necessary for190cm →789±49,740–840 (fully unrounded bounds would incorrectly show835).

## RangeBar props

`{value:number,low:number,high:number,min?:number,max?:number,size?:"large"|"compact",dashed?:boolean,label?:string,unit?:string,locale?:"nl"|"en",ariaLabel?:string,className?:string}`.
Defaults min=value−60/max=value+60; size large; unit mm; locale nl; label Zadelhoogte/Saddle height. Explicit min/max support other calculators. role img, localized autogenerated aria e.g. "Zadelhoogte 787 mm, bereik 765 tot 810 mm"; optional ariaLabel override. DM Mono bounds, lime+ink zone, ink marker, dashed openwarning, token-only styling,400ms motion disabled under prefers-reduced-motion. Usage: `<RangeBar value={result.adviceMm} low={result.lowerMm} high={result.upperMm} dashed={state.dashed} locale={locale}/>`.

Blank height returns status none/result null; valid height with no inseam returns status none with a valid estimated result. Render based on result presence, not status none. Invalid inputs return error/result null.
