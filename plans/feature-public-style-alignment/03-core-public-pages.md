# Step 03: Core Public Pages

## Objective

Apply the new public styling contract to the highest-impact website pages first.

## Target Pages

- home page
- about
- pricing
- why-bikefit-matters
- faq
- contact

## Tasks

1. Restyle each page using the shared public primitives.
2. Strengthen hero framing and section hierarchy.
3. Replace plain text blocks with better-framed content sections where appropriate.
4. Standardize CTA bands and internal link presentation.
5. Preserve page copy and SEO structure unless a layout adjustment requires small content grouping changes.

## Acceptance

- Each target page has a clearer hierarchy than before.
- Sections use the same visual grammar across pages.
- CTA treatment is consistent and visually stronger.
- No page becomes heavier or more confusing on mobile.
