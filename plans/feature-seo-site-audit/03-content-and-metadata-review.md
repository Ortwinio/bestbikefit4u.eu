# Step 03: Content And Metadata Review

## Objective

Assess whether the most important public pages have strong metadata and crawl-oriented content signals.

## Priority Pages

- `/`
- `/pricing`
- `/how-it-works`
- `/calculators/bike-fit`
- `/calculators/saddle-height`
- `/pain`
- first five `/pain/[slug]` pages
- `/guides`
- a representative `/guides/[slug]`
- `/use-cases`
- a representative `/use-cases/[slug]`
- `/case-study`

## Tasks

1. Review for each priority page:
   - title quality
   - meta description quality
   - canonical correctness
   - alternate locale coverage
   - OG/Twitter metadata presence
   - visible H1/topic alignment
   - internal links to adjacent relevant pages
2. Flag thin-content or weak-search-intent issues.
3. Identify pages that need:
   - stronger copy targeting
   - richer internal links
   - FAQ/schema improvements
   - clearer conversion paths

## Output

Create `output-03-content-review.md` with:
- page
- current strengths
- issues
- proposed improvement
- priority

## Acceptance Checks

- review covers both metadata and visible page intent
- output distinguishes technical fixes from copy/content improvements
- pain pages and calculators are included, not only generic marketing pages
