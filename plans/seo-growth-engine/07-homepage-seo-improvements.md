# Prompt 07 — Homepage SEO Improvements

## Goal

Turn the homepage into a stronger SEO hub without discarding the current conversion-focused layout.

## Repo Reality

- The homepage already includes Organization + WebSite JSON-LD
- It already contains guide teasers, but no structured calculator hub section
- It needs stronger internal links into calculators and use cases

## Deliverables

1. Keep the current hero and conversion structure intact
2. Add a “popular tools” block that links to public calculators
3. Add a “rider scenarios” or equivalent block linking to `/use-cases`
4. Keep JSON-LD centralized via the shared SEO utilities where practical

## Acceptance Criteria

- Homepage links directly into the key acquisition pages
- No regressions to existing CTA tracking or layout behavior
- The homepage remains server-rendered and locale-aware
