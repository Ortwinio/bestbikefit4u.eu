# SEO Growth Engine — Monitoring Checklist

## Release Checks

1. Open `/sitemap.xml`, `/sitemap-pages.xml`, `/sitemap-calculators.xml`, and `/sitemap-guides.xml`
2. Spot-check:
   - `/calculators/bike-fit`
   - one `/use-cases/[slug]`
   - one `/tire-pressure/[slug]`
   - one `/bandenspanning/[slug]`
3. Validate structured data for the pages above in Google Rich Results Test
4. Confirm canonical and hreflang output on one EN and one NL page

## Search Console Setup

1. Submit `https://bestbikefit4u.eu/sitemap.xml`
2. Request indexing for:
   - `/calculators/bike-fit`
   - `/use-cases`
   - 2 representative programmatic tire-pressure pages
3. Monitor coverage for indexing errors or alternate/canonical mismatches

## Monthly Review

1. Review Search Console performance by page group:
   - calculators
   - use cases
   - guides
   - tire-pressure programmatic pages
2. Check pages with impressions but weak CTR and revise title/description
3. Check pages with clicks but weak engagement and improve internal links or CTA placement
4. Add new long-tail programmatic pages only after confirming existing ones are indexing cleanly
