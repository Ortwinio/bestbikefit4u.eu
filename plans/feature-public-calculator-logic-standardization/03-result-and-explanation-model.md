# Step 3: Result And Explanation Model

## Objective

Move the calculators from single-point answers toward a standardized “safe range + likely center” result format with visible drivers.

## Tasks

1. Define the standard result pattern:
   - recommended value
   - recommended range
   - confidence level
   - what affected the result
   - what to adjust first
   - what to validate on the next ride
2. Define calculator-specific examples:
   - saddle height: range + start point
   - bar drop or bike-fit targets: range + safer center
   - frame size: shortlist/rank order
   - crank length: recommendation + recheck dependencies
   - tire pressure: range + center if appropriate
3. Define “why your result changed” logic:
   - primary drivers
   - secondary modifiers
   - plain-language driver explanations
4. Define “what this tool does not cover” content for every calculator.
5. Define how contradictions or lower-confidence outputs should be phrased.

## Output

Create `output-03-result-explanation-model.md`.

## Success Criteria

- Public calculators stop presenting results as isolated single answers where a range is more honest.
- Explanation logic is standardized instead of page-specific copy improvisation.
- The model makes the system feel intelligent and transparent.
