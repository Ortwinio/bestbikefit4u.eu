# 09 — Navigation, SEO, and Copy

## Objective

Define discovery and copy wiring for the gearing calculator family.

## Public discovery

- footer calculator links
- homepage calculator grid
- related links from bike-fit, saddle-height, and bike pages where relevant
- sitemap inclusion

## Dashboard discovery

- sidebar item under tools
- bike detail gearing card CTA
- optional dashboard home/setup surfaces later

## SEO targets

Public content should support searches like:

- gear ratio calculator
- speed at cadence calculator
- climb gearing calculator
- cassette size for mountains
- what gearing do I need for the Alps

## Copy rules

Public:

- practical
- fast
- low-ego
- avoid fake certainty

Dashboard:

- precise
- event-aware
- recommendation-oriented

## Deliverable

Prompt for i18n strings, footer/homepage/nav wiring, metadata, FAQ, and related-links updates.
