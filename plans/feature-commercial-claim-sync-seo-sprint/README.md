# Commercial Claim Sync SEO Sprint

## Goal

Create an implementation-ready content pack that aligns commercial messaging, SEO intent, and conversion copy across the public growth pages for BestBikeFit4U.

## Background

The sprint brief requires synchronized commercial claims, stronger analytics and SEO foundations, and clearer conversion copy for cyclists who want:

- more comfort
- better performance
- more confidence that a bike fits before they buy or change setup

The copy must stay conservative:

- no unsupported categories shown publicly
- no PDF/report claim unless the feature is live
- all commercial references in EUR

## Scope

In scope:

- final H1/H2 structure for 10 sprint pages/assets
- publish-ready medium-length copy
- page-level SEO direction
- CTA system
- internal link map
- proof requirements
- illustration directions aligned with BestBikeFit4U brand colors

Out of scope:

- code implementation
- analytics event wiring
- ad conversion setup
- production publishing

## Approach

1. Use the existing SEO/growth plans and current brand tokens as the baseline.
2. Build one consistent conversion framework across all pages.
3. Keep pain-led content fit-first and non-medical.
4. Add illustration guidance that is reusable by design and frontend teams.

## Deliverables

- `output-01-page-pack.md` — consolidated sprint content pack

## Acceptance Criteria

- All requested pages/assets have a final H1 and H2 structure.
- Each page includes medium-length publish-ready copy.
- Each page includes search intent, keyword cluster, CTA, internal links, proof needs, title/meta, and schema guidance.
- Illustration directions are relevant and aligned to BestBikeFit4U visual tokens.
- Claims remain conservative and compatible with the sprint constraints.
