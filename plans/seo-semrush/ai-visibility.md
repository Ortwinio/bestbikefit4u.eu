# AI visibility: fixed question set

Version 1 — 3 October 2026. This is a manual measurement protocol, not a results report.
Use these same 20 questions each month: ten Dutch questions and their ten English equivalents.
Do not add the brand name, a preferred website or extra context to a question.

## How to run

1. Run the set monthly on ChatGPT, Claude, Perplexity and Google AI Overviews where available.
   Keep a run ID and record the date, assistant/model or product label, search mode, country,
   interface language and signed-in status. Keep these conditions consistent; document changes.
   Do not assume the different products or their modes are directly comparable.
2. Start a fresh conversation for each question, without prior messages or personalization where
   you can disable it. Paste the question exactly once, in its listed language. For Google,
   submit it as the search query and inspect the AI Overview, not ordinary search results.
   Do not follow up, regenerate until the brand appears or ask for BestBikeFit4U specifically.
3. Save the first answer and its visible citations as a screenshot or export, using run ID,
   assistant and question ID in the evidence filename. Record only what you actually observe.
   Do not count sources that you infer the assistant might have used.
4. In the log, `mentioned` is `yes` only if the answer explicitly names BestBikeFit4U or its
   domain, including a visible source label; otherwise use `no`. Record every cited
   BestBikeFit4U URL exactly as displayed or linked. Leave that cell blank when none is cited.
   A mention without a link is still `yes`; it does not count as a citation.
5. If an assistant is unavailable or Google shows no AI Overview, record that status and leave
   `mentioned` and cited URL blank. This is not a negative brand result. Keep failed attempts
   in the log rather than silently replacing them with successful retries.
6. Compare observed mentions and citations separately, using completed answers as the denominator
   and reporting the completed/attempted count. Compare matching language, questions, assistant
   and mode. Retain earlier runs; do not overwrite them. Note changed product conditions and
   question-set versions. These small repeated samples are descriptive, not proof of causation
   or a guaranteed ranking. Do not publish any scores until real observations exist.
