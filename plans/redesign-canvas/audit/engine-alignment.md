## Reading key and source precedence

`match` means the input/output contract agrees; `design-only` means a mockup addition or temporary arithmetic that can be replaced without changing the interface; `must-fix` means the interface, range, unit, or claim needs correction. Defaults supplied only by the canvas are example data, not measured rider data. This follows the no-invented-claims rule in `plans/redesign-canvas/README.md:16`.

References are repository-relative `file:line` anchors. In each board section, `canvas:LINE` means the full board path named in its heading. Steps apply to controls, not necessarily to engine validators. A missing bound is reported as unspecified, never inferred from an example.

Both background DOCX files were read using `textutil -convert txt -stdout`. The executable implementation is authoritative for this audit: public fit tools call `src/lib/public-calculators/fitAdapters.ts:63`, while account recommendations build inputs through `convex/recommendations/seedEngine.ts:100`. In particular, do not import the specification's narrower saddle guardrail into the design: the implemented range is `round(inseamMm × 0.86)` through `round(inseamMm × 0.91)` (`convex/lib/fitAlgorithm/calculations.ts:118`); separate risk warnings use 0.865/0.89 (`convex/lib/fitAlgorithm/constants.ts:248`).
