# Step 01 — Panel Surface Contract

## Goal

Define the exact visual and technical contract for panel-like surfaces.

## Tasks

1. Convert the product requirement into implementation rules for:
   - panel body
   - backdrop
   - text
   - buttons
   - links
   - inputs
2. Decide whether the contract should live in:
   - theme tokens
   - reusable utility classes
   - shared Prototyper UI wrapper styling
   - a combination of the above
3. Define the allowed use of opacity:
   - allowed for backdrop only
   - not allowed for the panel body itself
4. Define any exception policy for semantic panels.

## Deliverable

- a written panel-surface contract

## Done When

- the team has one unambiguous rule for popup-style surfaces
